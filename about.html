Sobre
Descrição
Gerenciador desktop de snippets de código com suporte a markdown, imagens e busca full-text.
Autor
Mário Oliveira
Stack
Electron + SQLite embarcado (better-sqlite3) + highlight.js + marked
Funcionalidades

Editor & visualização

  • Syntax highlighting via highlight.js para 10 linguagens (JavaScript, TypeScript, Python, HTML, CSS, Bash, JSON, SQL, Markdown, texto puro)
  • Renderização de Markdown com marked + sanitização DOMPurify; preview com syntax highlight em code blocks
  • 3 modos de visualização: Editor / Split / Preview
  • Autosave debounceado (400ms persistência, 150ms preview)
  • Tab no editor insere 2 espaços (não pula foco)
  • Botão de cópia em 3 contextos (header, painel editor, painel preview)
  • Cópia inteligente: no preview de markdown copia o texto formatado sem marcações

Busca & filtros

  • Busca full-text via SQLite FTS5 com prefix match (ex.: java casa javascript)
  • Normalização de acentos (código casa codigo)
  • Debounce de 500ms com rejeição de resultados obsoletos (race-safe)
  • Spinner inline + lista dimmed durante busca
  • Filtro por linguagem (dropdown)
  • Filtro por tags clicáveis na lista + picker de tags existentes
  • Filtros combinam em AND; chips ativos no topo, botão Limpar
  • Ordenação alfabética A→Z / Z→A com toggle
  • Contador no header (3 / 12 quando filtrado)

Imagens

  • Upload via diálogo de arquivo
  • Paste do clipboard (Ctrl+V) — útil pra screenshots
  • Drag & drop de arquivos pro editor com overlay visual
  • Galeria de thumbnails com título editável inline (click para renomear)
  • Modal de visualização full-screen com zoom (25%-400%) via slider vertical
  • Pan via click-and-drag quando ampliada
  • Atalhos no modal: Esc, +, −, Ctrl+0 (fit)
  • Pasta de imagens configurável com migração assistida (mover / copiar)

Persistência

  • SQLite embarcado via better-sqlite3 (zero dependência externa)
  • WAL mode + foreign keys cascading
  • Schema: snippets, images, users + virtual table FTS5
  • Triggers sincronizam FTS5 automaticamente em INSERT/UPDATE/DELETE
  • Lazy-loading: lista traz só metadados, code é fetchado sob demanda no select
  • Race protection no select rápido entre snippets
  • Caminho do banco visível em Preferências (+ botão Abrir pasta)

Atalhos de teclado

  • Ctrl+N — novo snippet (abre em modo editor)
  • Ctrl+S — forçar save imediato
  • Ctrl+F — foca a busca
  • Ctrl+D — duplicar snippet atual
  • Ctrl+E — exportar tudo pra JSON
  • Tab no editor — indentação 2 espaços

Outros

  • Autenticação com login/logout (padrão admin/admin)
  • Menu travado pré-login (só Help visível)
  • Persistência de bounds da janela (size, position, maximized)
  • Export de todos os snippets pra JSON via menu
  • Tema dark VS Code-inspired com scrollbars customizadas
  • Ícones SVG (Lucide) em todos os botões — consistente entre OSes
